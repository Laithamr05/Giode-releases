# Giode

Giode (جيود) is a Windows program for land surveying: calculations, plans, drawings and reports, in English and Arabic.

This page only holds the downloads. Source code is not published here.

## Download

Get **Giode-Setup-1.0.0.exe** from the [latest release](../../releases/latest).

Needs Windows 10 or 11 (64-bit). Nothing else has to be installed.

## Install

1. Run `Giode-Setup-1.0.0.exe`. It installs for you alone, with no administrator needed. Choose "all users" at the start if you want it for everyone on the computer.
2. The installer is not signed with a publisher certificate yet, so Windows may show **"Windows protected your PC"**. Choose **More info**, then **Run anyway**.
3. Giode starts with a 30-day trial. After that, your jobs still open for viewing, printing and exporting; nothing you made is held back.

## Licence

Each computer needs its own licence key. In Giode, open Settings > Licence to see this computer's code, send it to the publisher, paste the key you get back, and press Activate. No internet connection is needed. The licence agreement is shown during setup.
